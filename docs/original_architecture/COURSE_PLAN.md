# 课设任务书：视觉驱动的空气吉他交互系统

> 用途：直接丢给 Claude / 开发总指挥做架构与拆任务。  
> 课程性质：本科计算机课设（非毕设），工期建议 2–3 周。  
> 作者侧约束：学生有 MediaPipe / OpenCV / Python 可落地能力；有鸿蒙背景可作加分项，**不是必须**。

---

## 0. 一句话目标

用笔记本摄像头实时识别双手：左手决定「弦 + 品位 / 和弦」，右手扫弦触发发声，画面叠加虚拟琴颈，做出可演示的空气吉他 Demo。

| 项 | 内容 |

## 2. 功能范围（Must / Should / Could）

### Must（验收必过）
1. 实时摄像头预览（≥15 FPS 可用，目标 ≥20 FPS）
2. MediaPipe Hands 双手检测与关键点绘制
3. 虚拟琴颈：由双手腕或固定 ROI 定义 6 弦 × N 品位网格（建议 N=4 或 5，降低难度）
4. 左手：指尖落入网格 → 输出当前弦号 + 品位（或映射为预定义和弦）
5. 右手：检测「扫弦」（指尖穿过琴颈线 + 速度阈值）→ 触发一次发声
6. 发声：至少 6 根空弦音 + 若干和弦（用 MIDI / pygame / simpleaudio / FluidSynth 任一）
7. 画面 HUD：弦名、当前和弦名、扫弦提示
8. 按 `q` / `Esc` 退出；可开关调试叠加层

### Should（建议做完，报告好看）
1. 时序滤波：连续 K 帧一致才切换和弦，减少抖动
2. 扫弦力度 → 音量
3. 单音模式 / 和弦模式切换（键盘快捷键）
4. 简单评测脚本：录一段视频或日志，统计误触发次数

### Could（加分，时间够再做）
1. 简谱 / 和弦进行跟练（对了再亮下一拍）
2. 录制回放（保存关键点序列 + 音频时间戳）
3. 鸿蒙 / 手机推流当摄像头源（加分项，单独里程碑）

## 4. 技术选型（给架构用，可替换但需说明）

- 语言：Python 3.10+
- 视觉：`opencv-python` + `mediapipe`（Hand Landmarker）
- 音频：优先 `mido` + 软件合成，或 `pygame.mixer` 预录音频；进阶 `fluidsynth`
- 结构：单进程实时循环即可；模块拆清，方便 Claude 分文件生成
- 不强制前端；若要 UI，可用 OpenCV 窗口，不要一上来上 Electron

推荐目录：

```
air-guitar/
  README.md
  requirements.txt
  main.py                 # 入口：摄像头循环
  src/
    camera.py             # 采集与分辨率
    hand_tracker.py       # MediaPipe 封装
    fretboard.py          # 虚拟琴颈几何 / 弦品位映射
    chord_mapper.py       # 指型 → 和弦 / 音符
    strum_detector.py     # 扫弦状态机
    audio_engine.py       # 发声
    overlay.py            # HUD 绘制
    config.py             # 阈值、网格、快捷键
  assets/                 # 可选：wav / sf2
  tests/                  # 几何与状态机单测（不强制跑摄像头）
  docs/
    design.md             # 架构说明（Claude 写）
    demo_script.md        # 演示脚本
```

## 5. 核心算法说明（课设报告要写清楚）

### 5.1 虚拟琴颈
- 默认：以画面中固定矩形 ROI 为琴颈（实现最快、最稳）
- 进阶：左右手腕连线为琴颈中轴，按比例划分 6 弦
- 品位：沿琴颈方向均匀切分 N 段

### 5.2 左手映射
- 取食指/中指/无名指/小指指尖 landmark
- 点到最近弦、最近品位 → `(string_id, fret_id)`
- 和弦模式：把当前指型向量与预定义模板做最近邻 / 汉明距离匹配  
  最少模板：`Am, C, D, Em, G, F`（6 个够演示）

### 5.3 右手扫弦状态机
状态：`IDLE → APPROACH → TRIGGER → COOLDOWN`
- 条件：指尖 y（或沿法向）穿过琴颈线，且 `|v| > V_TH`
- `COOLDOWN` 80–150ms，防止一次扫弦连响
- 方向：向下扫 / 向上扫可映射不同力度或扫弦方向音色（可选）

### 5.4 滤波
- 和弦：多数投票窗口（如 5 帧）
- 扫弦：冷却 + 速度阈值，禁止「贴线微抖」触发

## 9. 风险与对策

| 风险 | 对策 |
|---|---|
| 关键点抖动导致和弦乱跳 | 多数投票 + 切换滞回 |
| 扫弦连响 / 不响 | 调 V_TH 与 COOLDOWN；加调试轨迹 |
| 帧率低 | 降分辨率 640×480；landmark 模型选 lite |
| 没吉他乐理 | 只做预置和弦表，报告里附指型图 |
| 环境光差 | README 写清：正面光、纯色背景更稳 |

## 10. 演示脚本（答辩 2 分钟）

1. 开程序，亮出双手骨架与虚拟琴颈（10s）  
2. 左手比 Am，口播「当前和弦 Am」（10s）  
3. 右手慢扫、快扫，展示力度（20s）  
4. 切换到单音模式扫两下（15s）  
5. 关掉调试层，完整弹一段 Am–C–G–Em（40s）  
6. 总结技术点：关键点 → 网格映射 → 状态机扫弦（15s）
