# 课设展示脚本（约 3 分钟）

1. **0–20 秒：界面。** 打开 `start_windows.bat`，解释中文控制台左侧为实时视频，右侧为状态和演奏/曲目控制区。按 `F` 演示全屏。
2. **20–70 秒：实时视觉交互。** 真实左手在画面左边依次做 0、1、2、3 指和弦手势；真实右手在右边上下穿过绿色横线，产生吉他拨弦。说明去抖动、速度/冷却与左右手校正功能。
3. **70–100 秒：虚拟指板。** 点击右侧模式卡片或按 `M` 切至单音，左手食指指向不同弦/品位，右手扫弦触发单音。
4. **100–150 秒：完整音乐。** 右侧点击《小星星》，再点「▶ 播放示范曲」；解释“内置旋律事件 + 分解和弦伴奏 + 非阻塞音乐调度 + 原创合成吉他拨弦音色”，不是仅触发单个音效。演示暂停和停止。
5. **150–180 秒：稳定性与设计。** 切换《欢乐颂》，介绍窗口自适应、系统中文字体、无摄像头演示模式和测试框架。说明模拟演示不会当作真实视觉识别结果。

若现场没有外网，提前运行 `setup_windows.bat` 与模型下载步骤；若摄像头不可用，运行 `demo_windows.bat` 仍可独立试听曲目，并说明该模式使用的是模拟的双手数据。不要把自动播放曲目表述为“视觉系统自动弹奏的识别结果”，因为它是按钮触发的编排演奏功能。
