# 空气吉他 · 中文可视化演奏台（升级版）

这是在你提供的机器人视觉空气吉他项目上进行的**中文 UI + 完整示范曲**升级，而不是只改截图。保留左右手角色修复、MediaPipe 手部检测、六和弦手势、虚拟指板单音、扫弦状态机、45 个原创合成拨弦音色，以及既有代码结构。

## Windows + VS Code 快速启动

1. 建议使用 Windows 10/11、Python **3.11 x64**（Python 3.12 也可尝试）；确保安装 Python 时勾选 `Add Python to PATH`。
2. 解压项目 ZIP，进入 `AirGuitar_Vision_Project` 文件夹。
3. **双击 `setup_windows.bat`**，首次安装 OpenCV、MediaPipe、Pillow、pygame 等依赖，需要互联网。
4. **双击 `demo_windows.bat`**：先看中文界面、点击右侧「播放示范曲」。此模式不需要摄像头/MediaPipe 模型。
5. **双击 `start_windows.bat`**：启用真正的摄像头与手部识别。首次自动下载 Hand Landmarker 模型，需要联网，之后正常缓存离线使用。

VS Code 终端也可以执行：

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py --demo
.\.venv\Scripts\python.exe main.py
```

如果之前安装过旧版项目，请务必**重新运行 `setup_windows.bat`**，新版新增 `Pillow` 以显示中文字体。

## 中文界面与演奏区

- 默认画布 1440 × 900，摄像头画面与右侧控制卡片彻底分离；在 Windows 小屏设备上会尝试自动缩放窗口以完整显示控制区。
- 点击右上角「全屏 F」可全屏；再次点击或按 `F` 返回窗口。
- 真实**左手放在镜像画面左侧**选和弦（或单音模式选择指板弦/品位），真实**右手放画面右侧**上下穿过绿色扫弦线来发声。
- 如果摄像头对左右手判定颠倒，仍可按 `H` 切换手部标签校正。这不会交换画面位置。
- 和弦模式下保留浅色位置提示，但不再把整个六线指板重压在人物脸部；**单音模式**下显示指板网格，方便定位。
- 左手和弦手势：**0 指 Em、1 指 Am、2 指 C、3 指 D、4 指 G、5 指 F**。它们是课程教学用的象征性手势，不是真实吉他按弦指法。

## 新功能：吉他示范曲自动演奏

右侧「示范曲播放器」可使用鼠标操作，无须移动摄像头前的手：

1. 点击「**小星星**」或者「**欢乐颂**」选择曲目。
2. 点击绿色「**▶ 播放示范曲**」，听到带旋律和分解和弦伴奏的完整短曲。
3. 同一个按钮可**暂停 / 继续播放**；右侧「■ 停止」立即停止。
4. 播放时可以看摄像头、关键点和进度条。为了不让手势误扫弦盖过音乐，**自动播放期间不触发人工拨弦声音**；暂停或停止后恢复手动演奏。

**曲目时长**：小星星约 26 秒；欢乐颂约 18 秒。旋律来自公共领域作品；使用项目原创 Karplus–Strong 模拟拨弦 WAV 的组合编排（并非实物吉他录音）。既保留吉他音色，也能清楚听出具体旋律和节奏。

**还提供可单独打开试听的音频文件**：

- `assets/demo_song_twinkle.wav`
- `assets/demo_song_ode.wav`

两首曲子的实时播放器都根据节拍在程序中调度音符，而不是把整段 WAV 当作唯一可用的播放器；`tools/render_song_wav.py` 用来重新生成上述试听 WAV。

## 键盘与鼠标

| 操作 | 功能 |
|---|---|
| 鼠标点「小星星 / 欢乐颂」 | 切换指定的示范曲 |
| 鼠标点「播放 / 暂停 / 继续 / 停止」 | 播放器控制 |
| `P` / `T` / `N` | 播放或暂停 / 停止 / 下一首 |
| `M` | 和弦 / 单音切换（也可点击右侧模式卡片） |
| `F` | 全屏 / 窗口切换 |
| `H` | 左右手标签校正（真实摄像头时） |
| `S` | 静音 / 恢复（或点击右上角音频状态按钮） |
| `D` | 调试信息显示开关 |
| `空格` | 人工拨弦测试（自动演奏期间不干扰旋律） |
| `1–6` / `0` | 手动固定 Em / Am / C / D / G / F；`0` 取消固定 |
| `Q` / `Esc` | 退出 |
| `--demo` 下 `A` | 自动合成手部画面 / 手动控制 |
| `--demo` 单音模式 `I/J/K/L` | 移动弦与品位 |

## 检查 & 运行

```powershell
python main.py --demo              # 无摄像头，音乐和图形照常工作
python main.py --smoke-test        # 离线渲染 1440x900 中文 UI，保存 artifacts/smoke_test.png
python main.py                     # 真实摄像头（需要模型）
python main.py --camera 1          # 使用其他摄像头
python main.py --mute --demo       # 无声界面测试
python -m pytest -q               # 回归测试
python tools/render_song_wav.py    # 重新合成两首可试听的 WAV
```

模型地址和故障说明参见 `tools/download_model.py`。Windows 字体默认优先使用系统自带的**微软雅黑、黑体或宋体**，没有额外字体文件或字体下载依赖。若音频无法播放，请检查声卡/扬声器、Windows 音量和 `pygame` 安装；如首次模型下载失败，可单独运行 `python tools/download_model.py`。

## 课程答辩说明

- 视觉识别路径：OpenCV 摄像头画面 → MediaPipe 双手关键点 → 左手六手势/单音 → 右手扫弦触发 → 合成吉他音色。
- 纯音乐演奏路径：内置曲目/节奏事件 → 单调时钟调度 → 多通道吉他拨弦音色（无 `sleep` 阻塞）。
- 两套路径共享一个音频引擎，但自动演奏时优先保证曲目清晰。
- 保留上传的原始课设文档于 `docs/original_architecture/`。旧的左右手功能颠倒问题继续用 `DEFAULT_HAND_ROLE_SWAP=True` + `H` 校正，未退回旧行为。
- **验证边界**：离线测试/截图/曲目 WAV 不能替代真实摄像头、声卡和 Windows 设备联调，最终效果请在自己的电脑上测试。
